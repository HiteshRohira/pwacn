# Changelog

## 0.1.0 — 2026-09-17

- Added shared gesture arbitration for edge-back, sheets, tabs, and swipe actions.
- Added multi-snap sheets, scroll handoff, focus trapping, inert backgrounds, and keyboard-aware sizing.
- Added browser-history-aware preserved navigation, edge-only back gestures, scroll restoration, and progressive shared-element transitions.
- Added switch, segmented control, navigation bar, context menu, picker, toast, refresh control, reorderable list, and carousel primitives.
- Expanded the registry and CLI with safe local-change detection, `list`, and `doctor`.
- Added the `prefer-mobile-surface` ESLint rule and rule tests.
- Restored the dedicated interaction playground and expanded the Settings benchmark.
- Added multi-device browser testing, CI, release validation, and publishable package metadata.
